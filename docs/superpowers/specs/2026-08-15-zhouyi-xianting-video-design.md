# 周易仙庭 · 视频扩展设计文档

- 日期：2026-08-15
- 状态：已实施（512 条视频提示词，`validate.py` 0 项不通过）
- 关联：静态图集设计文档 `2026-08-09-zhouyi-xianting-design.md`、`~/.claude/skills/screenwriter/`、[video-prompting-skill](https://github.com/Square-Zero-Labs/video-prompting-skill)

## 1. 目标

在静态图集（64 卦 × 4 图像模型 × 2 画幅 = 512 条）之上，把同一套「八境 + 三旋钮」体系扩展到视频：每卦产出一条可执行的视频提示词，用于图生视频（首帧 = 该卦静态图），目标模型 **Seedance 2.5** 与 **MiniMax H3（Hailuo）**，两种结构（一镜到底 / 六镜头分镜）× 两种画幅（3:4 竖版 / 16:9 横版）。

**交付物：** 64 卦 × 2 模型 × 2 结构 × 2 画幅 = 512 条视频提示词 + 生成器 + 验收脚本 + skill。

## 2. 已锁定的决策

| # | 决策 | 取值 |
|---|---|---|
| 1 | 生成模式 | 图生视频为主：首帧 = 该卦静态图，视频层只加时间维度（运动/镜头/声音） |
| 2 | 目标模型 | Seedance 2.5（字节，与静态图 Seedream 同源）+ MiniMax H3（Hailuo） |
| 3 | 叙事引擎 | 六爻 = 六幕：初爻「潜」→ 二爻「见」→ 三爻「惕/进」→ 四爻「疑/跃」→ 五爻「盛」（高潮）→ 上爻「亢/止」 |
| 4 | 结构 | 两种都出：一镜到底 15s（六爻为六阶段）+ 六镜头分镜（每爻一镜） |
| 5 | 画幅 | 3:4 竖版（发布）与 16:9 横版（封面/视觉冲击），同静态体系 |
| 6 | 底本 | 爻辞来自 ctext.org（与卦辞同底本），`fetch_yaoci.py` 抓取并交叉验证 |
| 7 | 审美 | 去 AI 味：素材来源身份 =「高预算中式奇幻电影 35mm 胶片实拍」 |

## 3. 去 AI 味方法论（本设计的审美支点）

AI 视频模型的默认审美（平滑运镜、完美构图、商业调色、塑料材质、无重力）不主动关闭就会出现。方法论来自 zhouwei713/seedance-prompt 的 anti-ai-checklist，适配仙庭题材：

**第一步：定义素材来源身份。** 本系列的身份 = 一台 35mm 电影摄影机拍摄的高预算中式奇幻电影剧照级素材。由此推导一切质感要求：胶片颗粒、镜头呼吸、自然光衰减、真实材质、有机运镜、物理正确。

**第二步：负面约束关闭 AI 默认行为**（写入每一条提示词）：

| AI 默认行为 | 本系列的负面约束 |
|---|---|
| 平滑万向节运镜 | 无环绕、无甩镜、无 gimbal-smooth 运动；运镜有机、有呼吸感 |
| 现代商业调色（青橙） | 自然胶片色彩，无商业分级，无过度饱和 |
| 完美居中构图 | 微偏中心构图，顶部留白保持空旷 |
| 塑料感材质 | 真实材质：夯土颗粒、白玉温润、鎏金金属反射、青铜绿锈、朱漆剥落 |
| 无重力飘浮 | 物理正确：云有惯性、水有重力、鹤有翅振、雾有密度、光有衰减 |
| 过度锐化 | 微胶片颗粒，无锐化光晕 |

**第三步：植入非完美事件**（仙庭版）：风动经幡、云影掠过、光柱中尘埃浮动、水瀑摆动、鹤变换队形、镜头轻微呼吸。每幕至多一个，不堆砌。

**第四步：禁用抽象夸赞词**（全库）：高级、电影感、炸裂、唯美、震撼、epic、cinematic（作为夸赞）、stunning 等一律不写——写具体可观察的物理现象。

## 4. 转译设计：卦 → 视频

### 4.1 六爻六幕（叙事引擎）

每卦的六条爻辞构成六幕，五爻（君位）为高潮帧。幕的动作必须能由爻辞意象辩护，理由写入 `beats[].reason`。

例：泰 ䷊（坤上乾下 · 天地交）

| 幕 | 爻 | 爻辞意象 | 动作 |
|---|---|---|---|
| 1 | 初九 | 拔茅茹，以其彙 | 云海自下境升起，如草根连株拔起 |
| 2 | 九二 | 包荒 | 雾气向两侧漫开，露出更远地平线 |
| 3 | 九三 | 无平不陂 | 云浪一波波涌过两境，建筑纹丝不动 |
| 4 | 六四 | 翩翩 | 鹤群自天而降 |
| 5 | 六五 | 帝乙归妹 | 两境云气汇聚成光柱贯通天地（高潮） |
| 6 | 上六 | 城复于隍 | 光柱沉降消散，云海回落，归于宁静 |

### 4.2 镜头由卦德驱动

上卦主导运镜（画面主体在上），下卦影响机位微调（沿用静态锚点：下卦为坎/兑时贴水面平视）。经卦德性 → 运镜：

| 经卦 | 德性 | 运镜 |
|---|---|---|
| 乾 | 健 | 上升 Crane / 极缓推近 |
| 坤 | 顺 | 缓慢横移 Truck |
| 震 | 动 | 快速推镜 + 轻微震动 |
| 巽 | 入 | 纵深穿廊 Dolly |
| 坎 | 陷 | 缓降 Pedestal down |
| 离 | 丽 | 环绕 Arc（灯光明灭） |
| 艮 | 止 | 静止 Static + 极慢 Zoom |
| 兑 | 悦 | 轻摇 Pan（涟漪扩散） |

机位基线沿用静态锚点：平视远眺、地平线在画面中下部、不用低机位仰视。

### 4.3 三旋钮 → 时间弧

- **光时**：多数卦光时恒定（一镜 15s 内不演化，防变色）；少数卦（剥、遁、明夷等）允许演化，写入 `time_arc`。
- **天候**：静止态（晴/雾）→ 缓动（云流、雾漫、雨落、雪飘、风卷），非完美事件由此取材。
- **水势**：静 → 上涨 → 奔涌 → 干涸 即为水的运动弧，直接写进对应幕的动作。

### 4.4 音频

- `ambience`：风、水、檐铃、经幡、鹤鸣（与画面元素一一对应）
- `music`：编钟、古琴、铜磬（中式仙庭音色，高潮处一声长鸣）
- 无对白、无歌词、无字幕。

## 5. 数据模型

### 5.1 `data/hexagrams.json` 扩展：`yaoci`

`scripts/fetch_yaoci.py` 抓取 ctext 爻辞，写入每卦：

```json
"yaoci": [
  { "line": "初九", "text": "拔茅茹，以其彙，征吉。", "xiaoxiang": "拔茅征吉，志在外也。" },
  { "line": "九二", "text": "包荒，用馮河，不遐遺，朋亡，得尚于中行。", "xiaoxiang": "包荒，得尚于中行，以光大也。" }
]
```

交叉验证：页面首条卦辞必须与已有 `guaci` 一致，六爻标签严格递增，乾/坤可含第 7 条（用九/用六）。

### 5.2 新增 `data/video.json`

以卦序为键的 64 条记录。单一事实来源（视频层）：

```json
{
  "11": {
    "camera": { "shot": "中景固定机位微仰", "move": "极缓慢推近", "move_reason": "上卦坤主顺；泰之交，缓推如气升" },
    "beats": [
      { "line": "初九", "title": "拔茅", "shot": "全景",
        "action": "云海自下境升起，如草根连株拔起，雾气沿白玉台阶攀爬",
        "reason": "初九拔茅茹以其彙，群力初动" }
    ],
    "audio": { "ambience": "高空风声基底，云海低沉轰鸣，檐铃与风过经幡",
               "music": "编钟与古琴双声部，高潮处一声铜磬长鸣" },
    "time_arc": { "note": "正午恒定", "reason": "泰为天地交之盛时，光时不演化" }
  }
}
```

`*_reason` 规则延续静态体系：没有理由的值就是随手填的。

## 6. 生成器与验收

```
data/hexagrams.json (yaoci) + data/video.json + data/realms.json
        ↓ scripts/gen_video_prompts.py
video-prompts/            Seedance 2.5 条（制作笔记风格）
video-prompts-h3/         MiniMax H3 条（三字段 schema）
        ↓ scripts/validate.py（扩展视频验收）
```

视频验收项（新增，与静态项并列）：

- [x] 两模型条同源：六幕、运镜、色板、画幅一致
- [x] H3 条满足三字段 schema（integrated_multimodal_description / overall_soundscape / non_diegetic_music）
- [x] H3 镜头时间戳严格递增、落在时长内、[Shot 1] 无时间戳
- [x] 六幕与 `video.json` beats 一一对应，爻标签合法
- [x] 无抽象夸赞词（高级/电影感/炸裂/唯美/epic/stunning 等）
- [x] 负面约束齐备（无 gimbal 平滑/无商业调色/无塑料材质/无过度锐化）
- [x] 每幕至多一个非完美事件
- [x] 音频与画面元素对应（有鹤即有鹤鸣之类）
- [x] 无对白、无歌词、无字幕（画面禁令延续）
- [x] 顶部排字留白延续（H3 条在 [Shot 1] 与终镜注明）

## 8. 已知取舍

- **六镜头分镜每镜 2.5s**（15s 总长）：H3 官方建议按功能分配字数，而非平均；分镜版开头识别、中段奇观、结尾收束。
- **图生视频**：首帧=静态图。若首帧尚未出图，提示词仍可独立使用（模型会按描述生成首帧），但成套感以先出静态图为佳。
- **光时演化仅限少数卦**：15s 内变色易翻车，宁可光时恒定、靠天候/水势/灵禽运动拉开差异。
- **Seedance 条用中文、H3 条用中文**：本系列面向小红书/公众号中文发布；两模型对中文支持良好（Seedance 原生中文，H3 中文语料充分）。若英文模型表现更稳可后续出英文版（en_phrases 扩展）。
- **H3 的 `non_diegetic_music` 字段**：每卦给 1–3 句配乐说明；用户不想要配乐时可全局置 N/A。
