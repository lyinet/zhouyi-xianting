# 周易仙庭 · 卦象转译

## Overview

本 skill 是 `cinematic-image-prompt` 的**特化层**。它只负责一件事：把一卦转译成那个通用 skill 的 8 槽蓝图。四种模型方言的翻译工作交给通用 skill，此处不重复实现。

核心原则：**画面结构就是卦的结构本身，不是给卦义配插图。**

## 数据来源

| 需要什么 | 去哪拿 |
|---|---|
| 八境定义、签名色、英文译名、全局锚点 | `data/realms.json` |
| 某卦的上下卦、卦辞、三旋钮、灵禽、色板 | `data/hexagrams.json` |
| 已生成的成品提示词 | `prompts/upper-<经卦拼音>.md` |

**英文译名必须照抄 `realms.json` 的 `realm_en` / `elements_en` / `palette_en`，不得另译。** 天阙在 64 张图里只能是 the Celestial Gate。译名一漂，英文模型上的成套感立刻断裂。

## 叠合规则（支点）

**上卦占画面上方，下卦占画面下方。** 64 张一律遵守，这是主轴。

"远/近"与"高/低"是加强手段，不能替代上下：上境通常同时更远更高，下境通常同时更近更低。八纯卦（乾坤震巽坎离艮兑）为单境双重叠加，层层向上或层层向下推到极致。

这条规则自动画出周易的"交与不交"：
- 泰 ䷊（坤上乾下）→ 地宫的夯土庭院悬在天上，天阙的云海白玉台反在下方
- 否 ䷋（乾上坤下）→ 天阙高悬，地宫下沉，中间被一层死云彻底隔断

## 槽位映射

把卦的信息填进通用 skill 的 8 槽：

| 通用 skill 的槽 | 本 skill 的来源 |
|---|---|
| 1 画幅/机位 | `realms.json` → `global_anchors.aspect` / `.camera` |
| 2 主体 | 上下两境中占主导的那一境的核心建筑（**只能一个**） |
| 3 环境 | 两境的 `elements_zh` / `elements_en` |
| 4 三层纵深 | 暗前景框（就近取材于下境） / 上卦占上方 / 下卦占下方，最远层消隐 |
| 5 光 | `dials.light`（光时），只给一个主光源 |
| 6 氛围 | `dials.weather` + `dials.terrain` |
| 7 色板 | 上境色 + 下境色 + 光时点缀色（`accent_by_light`），两主一辅 |
| 8 质感 | `global_anchors.render_zh` / `.render_en` |

## 三旋钮推导

数据里已有取值时直接用。需要新推（如扩到爻图）时按此推导，并写入 `*_reason` 字段：

| 旋钮 | 取值 | 依据 |
|---|---|---|
| 光时 | 拂晓 / 正午 / 薄暮 / 夜 | 卦的**时**：初生取拂晓，盛大取正午，转衰取薄暮，晦暗取夜 |
| 天候 | 晴 / 薄雾 / 浓雾 / 雨 / 雪 / 罡风 | 卦的**势**：顺悦取晴或薄雾，险阻取风雨雪，蒙昧取浓雾 |
| 水势地势 | 静 / 上涨 / 奔涌 / 干涸 | 卦的**动向**：止待取静，进升取上涨，险涣取奔涌，穷困取干涸 |

**没有 `*_reason` 的旋钮值就是随手填的。** 理由必须站得住，能被读者反推出卦义。

## 灵禽

默认丹顶鹤，永远远景小点，**不露脸**。功能是给建筑尺度参照、给构图视觉焦点。

数量与状态随卦变：一只为孤（蹇、困），成对为合（咸、恆），群起为涣（涣、萃）。可换玄鸟、白鹿、锦鲤或一叶孤舟。

**不画近景人物、不画人脸。** 既保山水意境，又规避 AI 出图最不可控的失败模式，并免除 64 张维持人物一致性的负担。

## 输出

沿用 `cinematic-image-prompt` 的输出契约：每个模型一行标题 + 一个只含提示词的代码块，MJ 参数挂在行末。四条提示词必须同源——主体、光源方向、三层纵深元素、色板、画幅在四条中一致。

Midjourney 一律带 `--ar 3:4`，否定词写进 `--no` 而非正文。

## Red flags

| 症状 | 说明 |
|---|---|
| 下卦画到了画面上方 | 叠合规则破了，卦义反了。重画 |
| 天阙译成 Heavenly Palace / Sky Terrace | 译名漂移，照抄 `realm_en` |
| 出现近景人物或人脸 | 违反体系，换回远景灵禽 |
| 图上要求渲染卦名书法 | 64 张规模上不可靠，改为顶部留白后期排 |
| 旋钮值没有理由 | 卦义与画面脱节，补 `*_reason` 或重新推导 |
| 色板超过三色 | 模型会调出浑浊的灰，砍到两主一辅 |
