# 周易仙庭图集

把《周易》六十四卦各转化为一张中式仙庭风格的 AI 生成图，用于社交媒体连载。

每卦四条提示词，覆盖 Midjourney 8.2、GPT-Image-2、Nano Banana Pro、Seedream 5.0 Pro；两套画幅（3:4 竖版发布、16:9 横版封面），共 512 条。

**视频扩展**：同一套「八境 + 三旋钮」体系延伸到图生视频——六爻即六幕，每卦产出 Seedance 2.5 与 MiniMax H3 两种模型、一镜到底与六镜头分镜两种结构、3:4 与 16:9 两种画幅的视频提示词，共 512 条。详见 [视频扩展设计文档](docs/superpowers/specs/2026-08-15-zhouyi-xianting-video-design.md)。

## 核心设计

**八境组合法。** 八经卦各对应仙庭中的一处建筑：

| 经卦 | 境 | 经卦 | 境 |
|---|---|---|---|
| ☰ 乾 天 | 天阙 | ☴ 巽 风 | 风廊 |
| ☷ 坤 地 | 地宫 | ☵ 坎 水 | 水府 |
| ☳ 震 雷 | 雷坛 | ☲ 離 火 | 火殿 |
| ☱ 兌 泽 | 泽苑 | ☶ 艮 山 | 山门 |

**上卦占画面上方，下卦占画面下方。** 这条规则让画面结构直接等于卦的结构，而不是给卦义配插图。

对照第 11 卦与第 12 卦即可看出这套设计的全部：

- **泰 ䷊**（坤上乾下）地宫悬于天上，天阙反在下方；正午、长空澄澈、水气上下贯通、九鹤穿行两境 —— 天地交
- **否 ䷋**（乾上坤下）天阙高悬，地宫下沉；薄暮、一层死云横亘中际、下方水尽见底、一鹤困于下仰视不得上 —— 天地不交

同样两境，位置一翻，卦义自明，画面里不需要任何文字。

**三旋钮。** 每卦另由光时（拂晓/正午/薄暮/夜）、天候（晴/薄雾/浓雾/雨/雪/罡风）、水势地势（静/上涨/奔涌/干涸）三个值表达自身卦义，取值依据记录在 `*_reason` 字段中，可被反推。

**远景灵禽。** 默认丹顶鹤，永远是远景小点，不露脸。给建筑尺度参照与视觉焦点。不画近景人物与人脸 —— 既保山水意境，又规避 AI 出图最不可控的失败模式。

## 原文底本

卦辞、彖传、大象传取自[中国哲学书电子化计划 ctext.org](https://ctext.org/book-of-changes/zh)，每卦记录了来源 URL。

未用维基百科：`zh.wikipedia.org` 在开发所处网络不可达（同网络下 example.com 正常）。ctext 作为原文数据库，比百科条目更适合做底本。

## 上下卦分解的验证

整套视觉体系依赖 64 卦的上下卦分解正确，故不接受"凭记忆填写"。分解表通过四条独立验证：

1. 八经卦各作上卦恰 8 次、作下卦恰 8 次
2. 64 卦画互异且穷尽 2⁶
3. 32 对序卦全部满足反卦（上下颠倒）或错卦（阴阳全变）关系
4. 大象传物象与上下卦相符 64/64 —— 如屯「雲，雷」、既濟「水在火上」、未濟「火在水上」

第 3 条约束极紧，几乎任何单点错误都会被它抓出；第 4 条来自经文本身，与前三条完全独立。

## 宏大感从哪来

第二轮返工的教训：**宏大来自留白，不是把画面填满。**

首版把上下两境铺满整幅、雾气糊满全画，空间感被挤没了。参考图恰恰相反——建筑只占约三成，天空与云海占七成，而那片空正是让人觉得大的东西。

现有的宏大装置，`validate.py` 逐条强制：

| 装置 | 作用 |
|---|---|
| 留白：天空云海占三分之二 | 宏大的真正来源，画面不可填满 |
| 云海一路铺到地平线 | 无限远的空间感 |
| 建筑悬空不着地 | 超现实的体量 |
| 巨瀑自平台倾泻入云不见底 | 垂直尺度贯穿全画 |
| 三个极小袍服人影（一人橙红） | 最有效的尺度锤子 |
| 地平线附近第二座极小的同名境 | 二次尺度参照 |
| 前景受光的精细浮雕 | 「宫殿细致」的落点，且不再压暗 |
| 空气发光、暗部开放不压死黑 | 解决出图偏暗 |

**上境远看其形（`elements`），下境是脚下的台地、近看其雕（`ornament`）。** 这既符合摄影逻辑，也让叠合规则更有力——镜头站在一境之上仰望另一境。泰卦是站在天阙上看地宫悬于头顶，否卦是站在地宫里望不可及的天阙。

## 视频扩展：六爻即六幕

静态图集给出"帧内构成"（八境叠合、三旋钮、留白），视频扩展只加**时间维度**——而时间结构周易天然就有：**六爻 = 六幕**。

- **图生视频**：每卦静态图为第一帧，视频层只加运动、镜头、声音，成套感不破。
- **六爻六幕**：初爻起势 → 二爻显现 → 三爻转折 → 四爻过渡 → 五爻**高潮** → 上爻收束。幕的动作由爻辞意象驱动，`video.json` 的 `beats[].reason` 引用爻辞可辩护。
- **镜头由卦德驱动**：上卦定运镜（乾升/坤移/震动/巽入/坎降/离环/艮止/兑摇），机位基线沿用静态锚点。
- **去 AI 味**：素材来源身份 =「高预算中式奇幻电影 35mm 胶片实拍」——负面约束关闭平滑运镜/商业调色/塑料材质/过度锐化，每幕植入至多一个非完美事件，全库禁用抽象夸赞词。
- **产出**：64 卦 × 2 模型（Seedance 2.5 / MiniMax H3）× 2 结构（一镜到底 / 六镜头分镜）× 2 画幅 = **512 条**，`validate.py` 0 项不通过。

爻辞底本与卦辞同源（ctext.org），`scripts/fetch_yaoci.py` 抓取并交叉验证（页面卦辞与已有 `guaci` 一致、六爻标签严格递增）。

## 已知取舍

- **图上不渲染文字。** 64 张规模上 AI 渲染中文书法不可靠，构图预留顶部约五分之一留白，卦名与卦辞后期排版。
- **Midjourney 条不使用「天阙」这类自造专名。** 图像模型不认识它，只白占词数；专名的系列一致性作用由 GPT-Image-2 与 Nano Banana Pro 两条承担。
- **极小人影已允许。** 三个袍服人影立在栏边作尺度锤子，此尺寸下五官不成像，人脸崩坏风险极低；近景面孔与人群仍然禁止。
- **水势为「静」的占 29/64。** 这是卦义诚实的结果（艮止、恒久、大畜蓄皆当静），近半数画面水面平静，靠光时与天候拉开差异。出图时留意此处是否单调。
- **`--v 8.2`** 若账号不接受该版本号，去掉此参数即可。

生产顺序按上卦分组（同组共享上境，渲染描述可复用），**发布顺序按序卦 1–64**。
