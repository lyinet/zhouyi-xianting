# 周易仙庭图集

把《周易》六十四卦各转化为一张中式仙庭风格的 AI 生成图，用于社交媒体连载。

每卦四条提示词，覆盖 Midjourney 8.2、GPT-Image-2、Nano Banana Pro、Seedream 5.0 Pro，共 256 条。

## 核心设计

**八境组合法。** 八经卦各对应仙庭中的一处建筑：

| 经卦 | 境 | 经卦 | 境 |
|---|---|---|---|
| ☰ 乾 天 | 天阙 | ☴ 巽 风 | 风廊 |
| ☷ 坤 地 | 地宫 | ☵ 坎 水 | 水府 |
| ☳ 震 雷 | 雷坛 | ☲ 離 火 | 火殿 |
| ☱ 兌 泽 | 泽苑 | ☶ 艮 山 | 山门 |

**上卦占画面上方，下卦占画面下方。** 这条规则让画面结构直接等于卦的结构，而不是给卦义配插图。

对照第 11 卦与第 12 卦即可看出这套设计的全部：

- **泰 ䷊**（坤上乾下）地宫悬于天上，天阙反在下方；正午、长空澄澈、水气上下贯通、九鹤穿行两境 —— 天地交
- **否 ䷋**（乾上坤下）天阙高悬，地宫下沉；薄暮、一层死云横亘中际、下方水尽见底、一鹤困于下仰视不得上 —— 天地不交

同样两境，位置一翻，卦义自明，画面里不需要任何文字。

**三旋钮。** 每卦另由光时（拂晓/正午/薄暮/夜）、天候（晴/薄雾/浓雾/雨/雪/罡风）、水势地势（静/上涨/奔涌/干涸）三个值表达自身卦义，取值依据记录在 `*_reason` 字段中，可被反推。

**远景灵禽。** 默认丹顶鹤，永远是远景小点，不露脸。给建筑尺度参照与视觉焦点。不画近景人物与人脸 —— 既保山水意境，又规避 AI 出图最不可控的失败模式。

## 目录

```
data/
  realms.json       八境定义、签名色、英文译名、全局锚点
  hexagrams.json    64 卦单一事实来源（卦辞、彖传、大象传、旋钮、灵禽、色板）
prompts/
  upper-*.md        按上卦分 8 组，每组 8 卦，每卦 4 条提示词
scripts/
  build_hexagrams.py  由原文 + 旋钮表构建 hexagrams.json
  en_phrases.py       英文短语库（译名全库统一的唯一保障）
  gen_prompts.py      生成全部 256 条提示词
  validate.py         把验收标准变成可执行检查
.claude/skills/zhouyi-xianting/   转译规则 skill
docs/superpowers/specs/           设计文档
```

提示词是**派生产物**，不是手写散件。改画幅、换模型、扩到 384 爻都重跑脚本，不重写内容：

```bash
python3 scripts/gen_prompts.py && python3 scripts/validate.py
```

## 原文底本

卦辞、彖传、大象传取自[中国哲学书电子化计划 ctext.org](https://ctext.org/book-of-changes/zh)，每卦记录了来源 URL。

未用维基百科：`zh.wikipedia.org` 在开发所处网络不可达（同网络下 example.com 正常）。ctext 作为原文数据库，比百科条目更适合做底本。

## 上下卦分解的验证

整套视觉体系依赖 64 卦的上下卦分解正确，故不接受"凭记忆填写"。分解表通过四条独立验证：

1. 八经卦各作上卦恰 8 次、作下卦恰 8 次
2. 64 卦画互异且穷尽 2⁶
3. 32 对序卦全部满足反卦（上下颠倒）或错卦（阴阳全变）关系
4. 大象传物象与上下卦相符 64/64 —— 如屯「雲，雷」、既濟「水在火上」、未濟「火在水上」

第 3 条约束极紧，几乎任何单点错误都会被它抓出；第 4 条来自经文本身，与前三条完全独立。

## 已知取舍

- **图上不渲染文字。** 64 张规模上 AI 渲染中文书法不可靠，构图预留顶部约五分之一留白，卦名与卦辞后期排版。
- **Midjourney 条不使用「天阙」这类自造专名。** 图像模型不认识它，只白占词数；专名的系列一致性作用由 GPT-Image-2 与 Nano Banana Pro 两条承担。
- **水势为「静」的占 29/64。** 这是卦义诚实的结果（艮止、恒久、大畜蓄皆当静），近半数画面水面平静，靠光时与天候拉开差异。出图时留意此处是否单调。
- **`--v 8.2`** 若账号不接受该版本号，去掉此参数即可。

## 发布

生产顺序按上卦分组（同组共享上境，渲染描述可复用），**发布顺序按序卦 1–64**。
