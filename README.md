# 周易仙庭 · 起卦转译 Skill

一个可安装的 agent skill:**输入一个条件,起一卦,解一卦,现场写出一组仙庭风格的 AI 图像/视频提示词。**

装好 skill 后,在 agent 里这样说即可:

- 「给今天算一卦」——按日期时间起卦,出四模型静态提示词
- 「8月17号起个卦,16:9,只要 Midjourney 一条」
- 「报数 3 和 7,起卦,再出个视频分镜」——数字起卦 + MiniMax H3
- 「问一句:这件事该不该继续」——字数起卦
- 「泰卦,直接出图」——直给卦,跳过起卦
- 默认随提示词一并给出抖音标题、简介与话题;说「不要文案」即省略

一条链路:**条件 → 起卦(演算可复核)→ 解卦(引经文)→ 提示词(六种方言现场撰写)→ 抖音发布文案**。

## 安装

- 本项目内:skill 位于 `.claude/skills/zhouyi-xianting/`,自动生效。
- 全局:`cp -r .claude/skills/zhouyi-xianting ~/.claude/skills/`(或所用 agent 的用户级 skills 目录)。skill 自包含,数据全在 `references/` 内,无外部依赖。

## 核心设计

### 起卦:四种模式

| 模式 | 输入 | 方法 |
|---|---|---|
| 日期/时间(默认) | 今天、8月17号、现在 | 年支序 (公元年−4) mod 12+1,月日取公历数,时支序取提问时辰;上卦=(年+月+日) mod 8,下卦=再+时 mod 8,动爻=四数之和 mod 6(余 0 取 8/6) |
| 数字 | 任意一两个数 | 两数各定上下卦,和+时支定动爻;一数按位拆两半 |
| 字数 | 一句所问 | 前半/后半字数定上下卦,总字数+时支定动爻 |
| 直给 | 卦名/卦序 | 查表即得,动爻可选 |

传统梅花易数用农历;本 skill 采用**公历变体**,保证 agent 演算可复核。演算必须逐步展示,卦画必须与数据表 `lines` 核对一致才算数;动爻翻转得之卦,一并解。

### 八境组合法:画面结构 = 卦的结构

八经卦各对应仙庭一处建筑:

| 经卦 | 境 | 经卦 | 境 |
|---|---|---|---|
| ☰ 乾 天 | 天阙 | ☴ 巽 风 | 风廊 |
| ☷ 坤 地 | 地宫 | ☵ 坎 水 | 水府 |
| ☳ 震 雷 | 雷坛 | ☲ 離 火 | 火殿 |
| ☱ 兌 泽 | 泽苑 | ☶ 艮 山 | 山门 |

**上卦占画面上方,下卦占画面下方。**画面结构直接等于卦的结构,而不是给卦义配插图。对照第 11/12 卦即可看出全部:

- **泰 ䷊**(坤上乾下)地宫悬于天上,天阙反在下方;正午、云气上下贯通、九鹤穿行两境——天地交
- **否 ䷋**(乾上坤下)天阙高悬,地宫下沉;薄暮、死云横亘中际、一鹤困于下——天地不交

### 三旋钮与远景人物

每卦由光时(拂晓/正午/薄暮/夜)、天候(晴/雾/雨/雪/罡风)、水势(静/上涨/奔涌/干涸)表达卦义,取值与依据(`*_reason` 字段)记录在数据中,可被反推。

画面里**唯一的人物**是古风女子的背影:远景小点、不露脸、不写容貌年龄,不要求 64 张是同一人。人数与姿态编码卦义——**1 孤 / 2 合 / 3 群**,承接自原先的灵禽设定;衣色自动取该卦色板的点缀色,与画面同源。

### 宏大感:留白,不是填满

天空云海约占三分之二、建筑约三成;建筑悬空、巨瀑入云、三极小人影(一人橙红)作尺度锤、地平线附近第二座极小同境、前景受光浮雕、空气发光暗部不压死黑;顶部五分之一留白后期排卦名,图上不渲染文字。

### 视频扩展:六爻即六幕

六条爻辞 = 六幕,五爻(君位)高潮;镜头运动由上卦德性驱动(乾升/坤移/震动/巽入/坎降/离环/艮止/兑摇);**起卦所得动爻对应的幕加重运镜**。去 AI 味:素材身份锚定「35mm 胶片实拍的高预算中式奇幻电影」,负面约束关闭平滑运镜/商业调色/塑料材质,全库禁用「高级/电影感/epic」类抽象夸赞词。

提示词是 agent 按模板现场撰写的,不再有预生成库——一致性靠固定译名、固定模板骨架、锚点词表与交付前自检清单(见 `references/dialects.md`)保障。数据刷新链:

```
ctext.org → fetch_yaoci.py → data/hexagram_texts.json → build_hexagrams.py → references/hexagrams.json
任何数据改动后:python3 scripts/build_hexagrams.py && python3 scripts/validate.py
```

## 原文底本与分解验证

卦辞、彖传、大象传、爻辞取自[中国哲学书电子化计划 ctext.org](https://ctext.org/book-of-changes/zh),每卦记录来源 URL,抓取时交叉验证。上下卦分解不接受"凭记忆填写",经五条独立验证(`scripts/hexagram_checks.py`):八经卦各作上下卦恰 8 次;卦画与分解一致;64 卦画互异且穷尽 2⁶;32 对序卦全满足反卦或错卦;大象传物象与上下卦相符 64/64。CI 在每次 push/PR 时重跑全部检查。

## 已知取舍

- **纯 agent 现场撰写**:同一卦两次生成的提示词非逐字相同——模板骨架、槽位数据、锚点词与自检清单保证其同源与达标,而非字节级一致。
- **公历起卦变体**:牺牲梅花易数的农历传统,换取 agent 可复算、结果可复核;给农历则按农历数。
- **解卦措辞克制**:只作文化意象与观照,不给医疗/投资/法律断言。
- **Midjourney 条不用「天阙」自造专名**(模型不认识,白占词数),用 `realms.json` 的 `short_en`;专名一致性由 GPT-Image-2 与 Nano Banana Pro 承担。
- **`--v 8.2`** 若账号不接受该版本号,去掉即可。
- 历史版本(1024 条预生成提示词库)已删除,见 `docs/superpowers/specs/2026-08-17-zhouyi-divination-skill-design.md` 与 git 历史。
